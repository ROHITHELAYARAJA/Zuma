# Weekly review

Use the connected records relevant to the week: Calendar, Gmail, HubSpot, GitHub, Drive, and recent research. Read selectively and respect the user's stated priorities. Identify completed work, slipped commitments, upcoming deadlines, and decisions awaiting the user. Label missing data instead of guessing.

Return a five-area scorecard with factual progress and one next action per area. Then recommend no more than three priorities for the coming week, each with a desired result and a realistic time block. For Personal, use only details the user has chosen to share; do not infer health, financial, or family circumstances from private records.

When asked to apply the plan, update authorized records and calendar blocks and verify the result. Prepare messages as drafts until explicit sending authorization is given.
