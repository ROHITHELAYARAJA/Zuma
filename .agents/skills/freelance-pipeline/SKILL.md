# Freelance pipeline

Start with the user's target service, customer profile, geography, and capacity from the conversation or existing CRM. Read HubSpot deals and contacts plus relevant Gmail threads before proposing follow-ups. If lead discovery is requested, use an available Apify connector or Firecrawl to gather current public evidence, deduplicate it against HubSpot, and record the source URL and date. Never invent a prospect email, contact identity, budget, or intent.

Present a small ranked pipeline with reason, next action, owner, and due date. Create or update CRM records when the user asks for pipeline execution; verify each write. Prepare client messages as drafts until the user explicitly authorizes sending. Do not bulk contact leads without an explicit campaign instruction.

For a weekly review, report leads added, active opportunities, stale follow-ups, proposals awaiting response, and one concrete improvement to the sales process. Separate measured conversions from estimates.
